# Known limitations

HAOS is development, not an accepted production distribution. The master prompt remains the complete target.

- The bounded installed foundation gate passed at `2cebd11`: exact ISO bytes verified, actual UEFI/TCG installation and both guest receipts completed, covering Hermes health, fixture volume boundaries, observer/local-network denial, staged local recovery, UI/backend restart separation and offline queue persistence. Earlier policy-umask, DNS and systemd/procfs startup failures are corrected and evidenced. This does not accept the complete distribution, graphical owner onboarding or physical hardware. Historical billing failures are distinct from current public runs. Builds remain unsigned. An actual offline image [SBOM gate](SBOM.md) now checks installed Python/RPM coverage and preserves the npm graph; matching HAOS-image results, embedded-component/license/vulnerability review, provenance, reproducible pins, Secure Boot and update trust remain unfinished.
- Writable binds now receive root-broker named-agent ACLs on ext4/XFS/Btrfs with generation-aware original-permission recovery, and FAT/NTFS3 use verified agent masks. Actual runner ext4/XFS/Btrfs gates and source-bound installed foreign-owner write/rename/delete acceptance passed; see [exact evidence](HAOS.md). Previously granted disconnected volumes now remain in owner policy but are omitted from the prepared namespace and reported unavailable; root/publication/UID probes pass, matching installed proof remains required. Earlier cloud scratch filesystem probes failed with EOPNOTSUPP, not success. External chmod/permission changes and reconnection require stopped-runtime refresh; no continuous rights override exists. Same-system-disk data is conservatively denied. LUKS unlocking is owner work; live hotplug/remote filesystems unsupported. See [volume access](VOLUME-ACCESS.md).
- Shared host networking now has a required socket-UID nftables guard for local/private destinations with narrow backend/DNS/reply exceptions. At `2cebd11`, the real runner kernel probe passed IPv4/IPv6/mapped-address denial, existing-connection revocation, backend self/reply exceptions, denied firewall mutation and preserved other-UID traffic. Both installed boots separately proved service-UID denial of a privileged localhost listener. AF_UNIX abstract sockets, resolver-change brokerage and complete egress/exfiltration policy remain incomplete. Inherited SELinux permissive configuration has no enforcing proof.
- Durable native missions now have a separate authenticated Telegram/Discord ingress, root-only pairing/credential CLI and durable transport inbox/outbox. Managed local chat and existing voice-transcript callers use the same persistent controller; opaque admission receipts survive UI reload without resending. Pre-dispatch queued pause/resume now persists across controller restart and is exposed in Herald and explicitly authorized gateways, preserving deadline/backoff and refusing live or ambiguous replay. Local ordinary, actual Unix-peer and root-private-file probes passed; bundled adapter constructors/contracts were verified without connecting. Real provider/gateway round trip and new installed-service acceptance remain unverified. Attachments, complete voice-response playback, safe live-job pause/resume and WhatsApp/other adapters remain incomplete; see [gateway integration](GATEWAY-MISSIONS.md) and [native conversation](NATIVE-MISSIONS.md).
- Complete upstream turn is not independent goal proof. Ambiguity blocks intentionally. Background cleanup, resumable downloads and parallel worktrees need further work.
- Native host GUI bridge access is withheld; safe broker, genuine capture and authenticated remote stream missing.
- Complete saved theme revisions retain manifests/assets and offer native/Linux version selection. An actual isolated Chromium preview now captures representative shell CSS, checks readable controls and real raster decoding, and gates new saved revisions before activation. Five real renderer cases and filesystem/cross-language tests pass locally; matching CI and installed UI proof remain separate. Autonomous themes/skills still lack a restricted agent broker, capability-managed plugins, complete renderer resource budgets, golden-image/full-session regression, whole-session atomic swap and independent automatic crash rollback/watchdog/revocation; see [theme interfaces](THEME-SDK.md).
- Credential-isolated provider routing now has an owner CLI for actual pinned Codex OAuth, OpenAI/OpenRouter API keys and explicit compatible loopback models. Local HTTP, private-file/UID, interrupted-switch and pinned native resolver/Responses contracts passed; new kernel/socket/ISO acceptance remains pending. Real Codex/Telegram credentials were not supplied, so external model/tool/gateway turns are blocked, not claimed successful. A new server-side [observer gate](DASHBOARD-ACCESS.md) and root token rotation replace the legacy full dashboard token; actual local pinned HTTP/WS and UID probes pass, but matching installed acceptance remains required. Protected legacy settings need native graphical owner flows; general vault/log encryption, monetary/per-mission budgets and additional providers remain open. See [provider setup](PROVIDER-SETUP.md).
